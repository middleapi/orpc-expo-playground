# oRPC Expo Playground

A playground for exploring [oRPC](https://orpc.dev) with [Node.js](https://nodejs.org/) and [Expo](https://expo.dev).

## Getting Started

Start the development server:

```bash
pnpm run dev
```

- Visit [http://localhost:3000/api](http://localhost:3000/api) to explore the OpenAPI client.
- Visit [http://localhost:8081/](http://localhost:8081/) to explore the Expo app.
